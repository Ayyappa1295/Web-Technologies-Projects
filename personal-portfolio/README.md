## ▶️ How to Run

### Option 1 — Open Directly

Download or clone the repository and open:

```text
index.html
```

in any modern web browser.

### Option 2 — Clone Using Git

```bash
git clone https://github.com/Ayyappa1295/personal-portfolio.git
```

Navigate into the project:

```bash
cd personal-portfolio
```

Then open `index.html` in your browser.

---

## 🔧 Customization

Before deploying the portfolio, update the following:

### Profile Photo

Replace:

```text
assets/profile.jpg
```

with your professional profile photo.

### Resume

Replace:

```text
assets/resume.pdf
```

with your latest resume.

### Email

Update:

```text
your-email@example.com
```

with your actual email address.

### LinkedIn

Replace the LinkedIn URL with your actual profile URL.

### Project Links

Update the project links with the corresponding GitHub repositories or live websites.
