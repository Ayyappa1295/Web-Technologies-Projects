# 🚀 JobHub – Job Portal Web Application

JobHub is a modern and responsive **Job Portal Web Development Project** designed to connect job seekers with employers.

The application provides a professional interface for discovering jobs, viewing job details, applying for positions, managing candidate profiles and managing employer job postings.

---

## 🌐 Project Overview

JobHub is a frontend-based job portal developed using:

* HTML5
* CSS3
* JavaScript
* Responsive Web Design

The project demonstrates how a real-world recruitment platform can be structured from the frontend.
